# GTK4 Port Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move the xgui GTK backend from GTK 3.24 to GTK 4 with no deprecated GTK 4 API left, keeping the public xgui API.

**Architecture:** One switch commit ports the whole backend faithfully (List/Tree/ComboBox temporarily on deprecated GTK 4 widgets), then each complex widget is rewritten on the GTK 4 list-model widgets in its own commit. `GtkApplication` drives the lifecycle; synchronous public dialogs are built on async GTK 4 dialogs plus a nested `GMainLoop`.

**Tech Stack:** C++17, GTK 4.20 (`pkg-config gtk4`), GNU make (`Makefile.gtk`), bash test runner `tests/unit/run.sh` on a headless `gtk4-broadwayd` display, SWIG for Python.

**Spec:** `docs/superpowers/specs/2026-10-03-gtk4-port-design.md`

## Global Constraints

- Build with `pkg-config gtk4`; GTK 3 is no longer supported.
- Public headers `xgui/*.h` keep their signatures; the only addition is `Master::SetApplicationId(std::string const &id, bool unique = false)`.
- Default application id: `org.xgui.<prgname with every char outside [A-Za-z0-9_] replaced by _>`, flags `G_APPLICATION_NON_UNIQUE`.
- Window `position` and `onmove` are unsupported: setter warns and returns false, getter returns false, `linkEvent("onmove")` returns false.
- End state: every `xgui/gtk/*.cpp` compiles with `-Werror=deprecated-declarations`.
- Every commit compiles, `tests/unit/run.sh` passes, `CHANGES.md` is updated. No em dash characters. English code and comments. No AI attribution in commits, never `--no-verify`.

## Review Focus

- `Master::Quit()` called from inside a callback while `Run()` is on the stack: `Run()` must return cleanly without touching freed memory (covered by the lifecycle test in Task 1).
- Nested `Run()`/`Quit()` (modal loops): inner `Quit()` must return to the outer loop, not end the app (lifecycle test, Task 1).
- Modal file/message dialogs answered or closed by the user while no xgui window exists (dialog test with NULL parent, Task 1).
- List rows removed while selected: selection callbacks must not reference freed `XguiRow`/`Model` (selection test, Task 2).
- Tree nodes appended under a collapsed or never-expanded parent: they must appear when the parent is expanded (tree test, Task 3).
